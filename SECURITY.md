# Política de segurança

## Versões suportadas

A versão mais recente publicada na página de Releases é a única que recebe correções de segurança.

## Relatando uma vulnerabilidade

Não publique detalhes exploráveis, credenciais, cookies ou dados pessoais em uma issue pública. Entre em contato de forma privada com o mantenedor pelo perfil do GitHub antes de divulgar detalhes técnicos. Inclua a versão do aplicativo, a versão do Windows, o comportamento observado e passos mínimos para reprodução.

## Uso seguro

- Baixe o aplicativo somente da página oficial de Releases.
- Compare o SHA-256 do instalador com `SHA256SUMS.txt`.
- Não execute cópias modificadas ou obtidas de terceiros.
- Não forneça credenciais das plataformas ao aplicativo.
- Use `http://127.0.0.1:5000/overlay` no OBS e não exponha a porta 5000 à internet.

O projeto agrega mensagens públicas para exibição em overlay. Abuso, automação de spam, assédio, evasão de controles das plataformas ou qualquer uso que viole leis e termos aplicáveis não é autorizado.
